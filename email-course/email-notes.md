* Email Template Sizing Best Practices *
1. Template width: 600px/640px - 800px
2. Template height: up to 3,000px
3. Template file size: up tp 100kb
4. Template design tips:
    - Email header up to 200px
    - Important details at first 350px in height
    - Using responsive designs
    - Not using images to display all content
5. Images under 200kb each is best
6. Images up to 700kb made no impact on emails being delivered properly.
7. Under 2.5mb total for all images
